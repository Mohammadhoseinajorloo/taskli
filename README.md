# 🚀 Taskli - CLI Task Manager

> A robust, lightning-fast command-line task management tool built from scratch in **Python**, developed iteratively using **Scrum & Agile methodologies** (Solo Scrum).

## ✨ Features
- **Core CRUD Operations:** Add, list, complete (`done`), and delete tasks effortlessly.
- **Advanced Querying:** Filter tasks by status (`--status todo/done/all`) and search keywords case-insensitively (`search <query>`).
- **Reliable Storage:** Persistent local JSON-based storage engine with atomic safety.
- **CI/CD Pipeline:** Automated testing across multiple Python versions (3.10, 3.11, 3.12) using GitHub Actions.
- **Engineering Excellence:** Fully tested with `pytest`, strict adherence to Clean Code and Agile principles.

## 🛠️ Tech Stack & Tools
- **Language:** Python 3.10+
- **Testing:** Pytest
- **Project Management:** GitHub Projects (Kanban Board, Issues, Milestones, Scrum Sprints)
- **Automation:** GitHub Actions (CI)
